# Game data

`data/<gameVersion>/{meta,minehead,sneaking,hole}.json`, generated by `npm run data:update`
(`scripts/extract-data.ts`, schemas in `src/data/schemas.ts`). Do not edit by hand.

- Source tables: Morta1/IdleonToolbox `data/website-data/*.json` at the commit recorded in each `meta.json`.
  They are generated from the game's own tables; only data is taken, no Toolbox code.
- Names and values belong to Legends of IdleOn (Lavaflame2). Non-commercial fan tool.
- The source does not state its own game version. `meta.gameVersion` is the version the set is intended for;
  `npm test` cross-checks it against `fixtures/save.json` when present.
- Update: `npm run data:update -- --game-version <n> [--sha <toolbox commit>]`.
- Open question (licensing): whether committing these extracted tables is fine is the owner's call;
  to keep them out of git, add `data/` to `.gitignore` and run the update in CI/Docker instead.
